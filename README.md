**AiBlazor** — это проект, объединяющий API и Blazor-клиент для работы с пользовательской AI-моделью. Решение построено на .NET и демонстрирует создание веб-интерфейса для взаимодействия с искусственным интеллектом.

## 📋 О проекте

Проект представляет собой базовую инфраструктуру для интеграции AI-функций в веб-приложение на Blazor. Основная цель — показать, как можно создать клиентское приложение и API для обработки запросов к пользовательской модели машинного обучения.

## 🚀 Текущее состояние и функциональность

На данный момент в проекте реализовано:
*   **API** для взаимодействия с серверной частью.
*   **Blazor-клиент** с несколькими страницами и сервисами.
*   **Сервис переводов** (`Translation service and page`), интегрированный в веб-интерфейс.
*   **Механизм аутентификации** (`fixed login issue`), что говорит о наличии базовой системы авторизации.

Подробности о конкретной AI-модели, которая используется в проекте, пока не раскрыты.

## 🛠️ Технологический стек

Проект написан на следующих языках и технологиях:
*   **Языки:**
    *   HTML (61.1%) — для разметки интерфейса.
    *   C# (32.9%) — основной язык для логики API и Blazor-компонентов.
    *   CSS (6.0%) — для стилизации.
*   **Платформа:** .NET (проект содержит файл решения `.sln` и использует C#).

## ⚙️ Начало работы

Чтобы развернуть проект локально, выполните следующие шаги.

### Предварительные требования
*   Установленный [.NET SDK](https://dotnet.microsoft.com/download) (версия, совместимая с проектом, скорее всего .NET 6/7/8 или новее).
*   Редактор кода (рекомендуется [Visual Studio](https://visualstudio.microsoft.com/) или [VS Code](https://code.visualstudio.com/)).

### Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/kobubu/AiBlazor.git
    cd AiBlazor
    ```

2.  **Восстановите зависимости и соберите решение:**
    ```bash
    dotnet restore
    dotnet build
    ```

3.  **Настройка конфигурации:**
    > **Важно:** В проекте настроен `.gitignore` на исключение файла `appsettings.json`. Вам необходимо создать свой файл конфигурации, чтобы приложение работало корректно.
    *   Скопируйте пример конфигурации (если есть `appsettings.Example.json`) или создайте `appsettings.json` вручную в нужных папках.
    *   Заполните его необходимыми данными (например, строки подключения, ключи API).

4.  **Запустите приложение:**
    *   **Вариант 1:** Через .NET CLI:
        ```bash
        dotnet run
        ```
    *   **Вариант 2:** Откройте файл решения `AiBlazorSolution.sln` в Visual Studio и нажмите `F5`.

5.  **Доступ к приложению:**
    После запуска откройте браузер и перейдите по адресу, который укажет консоль (обычно `https://localhost:5001` или `http://localhost:5000`).
